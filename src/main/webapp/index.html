🎬 Cinema Management API

RESTful API for managing tickets and actors using Java Servlets and JSON.

🎟️ Tickets

GET /api/tickets - Get all tickets
GET /api/tickets?price=X - Filter by price (exact match)
GET /api/tickets?status=X - Filter by ticket status (partial match)
GET /api/tickets?sort=movie - Sort by movie title
GET /api/tickets?group=genre - Group by movie genre
POST /api/tickets - Create new ticket
PUT /api/tickets/{identity} - Update ticket (e.g., change status)
DELETE /api/tickets/{identity} - Delete ticket

⭐ Actors

GET /api/actors - Get all actors
GET /api/actors?name=X - Filter by actor name (partial match)
GET /api/actors?year=X - Filter by minimum birth year (e.g., 1980)
POST /api/actors - Create new actor
PUT /api/actors/{identity} - Update actor
DELETE /api/actors/{identity} - Delete actor
